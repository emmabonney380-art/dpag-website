⚡ Quick Start

Get your DPAG website live in just a few minutes:

Step 1: Prepare Your Assets

  1. Create an assets folder in your project root
  2. Add the DPAG logo images:
    • assets/dpag-logo.png - Colored version (recommended: 200x200px)
    • assets/dpag-logo-white.png - White version (recommended: 200x200px)
  3. Add background image: assets/hero-bg.jpg (recommended: 1920x1080px, optimized for web)

Step 2: Deploy to Netlify

  1. Push your code to GitHub
  2. Visit netlify.com
  3. Click "New site from Git"
  4. Select your GitHub repository
  5. Keep default settings (no build command needed)
  6. Click "Deploy"

Step 3: Add Your Domain

  1. In Netlify, go to Domain settings
  2. Add your custom domain
  3. Follow DNS setup instructions
  4. SSL certificate is automatic ✓
✓ Done! Your website is now live and accessible worldwide.

📧 Contact Form Setup

The contact form is ready to receive submissions. To process form data, you have several options:

Option 1: Netlify Forms (Recommended - Free)

  1. Form already has netlify attribute in HTML
  2. Deploy to Netlify
  3. Go to Netlify Dashboard → Forms tab
  4. Submissions appear automatically ✓
  5. Set up email notifications in settings

Option 2: Using Formspree

  1. Visit formspree.io
  2. Create account and new form
  3. Update form action in HTML:
    <form action="https://formspree.io/f/YOUR_ID" method="POST">
  4. Test the form

Option 3: Using Your Own Backend

If you have a backend server, update the form in index.html:

<form action="https://your-api.com/contact" method="POST"> <!-- form fields --> </form>
⚠️ Important: Never expose API keys in frontend code. Always use serverless functions or backend endpoints for sensitive operations.

🔍 SEO & Performance Optimization

SEO Checklist

  • Update meta descriptions in <head>
  • Add your business name to all title tags
  • Include location keywords (Ghana, Accra)
  • Add alt text to all images
  • Install Google Analytics
  • Submit sitemap to Google Search Console
  • Add schema markup for local business

Adding Google Analytics

Add this to the <head> section of index.html:

<script async src="https://www.googletagmanager.com/gtag/js?id=GA_ID"></script> <script> window.dataLayer = window.dataLayer || []; function gtag(){dataLayer.push(arguments);} gtag('js', new Date()); gtag('config', 'GA_ID'); </script>

Replace GA_ID with your Google Analytics ID.

Performance Tips

  • Compress all images (TinyPNG, ImageOptim)
  • Enable GZIP compression on your server
  • Use browser caching headers
  • Minimize CSS and JavaScript in production
  • Use a CDN for image delivery
  • Test with Google PageSpeed Insights

🗺️ Google Maps Integration

The website includes an embedded Google Map. To customize:

Get Your Google Maps Embed URL

  1. Visit maps.google.com
  2. Search for your business location
  3. Click the location
  4. Click "Share" → "Embed a map"
  5. Copy the iframe code

Update the Map in Your Website

Replace the iframe in the Contact section:

<iframe src="https://www.google.com/maps/embed?pb=..." width="100%" height="300" style="border:0;" allowfullscreen="" loading="lazy"></iframe>
💡 Tip: Include your business address in Google My Business for better local SEO visibility.

🔧 Troubleshooting

Images Not Showing

Problem: Images appear broken on deployed site

Solution:

  • Check image paths are relative (not absolute)
  • Verify images are in correct folder structure
  • Ensure image filenames match HTML exactly
  • Check file permissions on server

Mobile Menu Not Working

Problem: Hamburger menu doesn't respond on mobile

Solution:

  • Check JavaScript is loaded (no console errors)
  • Verify viewport meta tag is in <head>
  • Clear browser cache
  • Test in different browsers

Form Not Submitting

Problem: Contact form shows error

Solution:

  • Check form action attribute is correct
  • Verify all required fields have names
  • Check browser console for errors (F12)
  • Test in incognito mode (disable extensions)

Page Loading Slowly

Problem: Website takes too long to load

Solution:

  • Optimize and compress all images
  • Enable browser caching
  • Use CDN for static files
  • Minimize CSS and JavaScript
  • Run PageSpeed Insights test
